Privacy & file handling

Toolverse is a collection of utility tools. The supplied website code performs image editing in your browser, and PDF numbering locally using an open-source library. Files are not intentionally uploaded to a Toolverse server by these editors.

On-device files

Images and PDFs selected in the editors are processed inside your browser or Android WebView. Exporting or sharing a file passes the result to the destination you choose. Background erasing is a local color-based operation, not a remote AI service.

Device preferences

Theme choice, saved tools and recently used tools are stored in your browser's local storage. You can clear that storage using your browser or app data controls.

Third-party assets and hosting

The site may retrieve fonts from Google Fonts. The PDF editor loads pdf-lib from jsDelivr on first use. These services and the website hosting provider may receive network information such as your IP address and user-agent as part of normal delivery. The website code in this repository does not contain an advertising SDK or analytics tracker at this stage.

About ads

If advertising, analytics, accounts or remote image-processing services are added later, this policy must be updated before release and any required consent or disclosures must be implemented.

Contact

For questions, contact the app publisher using the contact details on the app's store listing once published.
